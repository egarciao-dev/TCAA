# Titan Campus Algorithmic Assistant (TCAA)

TCAA is a Python desktop app that helps students explore classic algorithms using campus-style scenarios:

- Campus Navigator – Graph algorithms on a visual campus map  
- Study Planner – Greedy vs Dynamic Programming for study tasks  
- Notes Search Engine – Naive, Rabin–Karp, and KMP pattern matching  
- About / Info Tab – Quick Big-O and algorithm cheat sheet  

Built with Tkinter, it runs entirely on your machine (no internet required).

---

## 1. Features

### 1.1 Campus Navigator

Interactive map where buildings are nodes and walkways are edges.

You can:
- Add buildings with names and positions on a canvas
- Add paths between buildings with:
  - Distance
  - Accessibility (accessible / non-accessible)
  - Open / closed status
- Drag buildings to rearrange the layout
- Filter paths by:
  - Accessible only
  - Use distance or time as the weight

Algorithms:
- BFS – unweighted shortest path (fewest hops)  
- DFS – traversal order plus “any” path between two buildings  
- Dijkstra – weighted shortest path using distance or time  
- Prim (MST) – builds a minimum spanning tree for the campus graph (demo file)  

The GUI highlights:
- Path edges used by an algorithm
- Closed or non-accessible edges
- Visited nodes in the order they’re processed

---

### 1.2 Study Planner

Simple planner that compares **Greedy** scheduling vs **Dynamic Programming (0/1 Knapsack)**.

You provide:
- A list of tasks (name, required time, importance/value)
- Total available time (capacity)

The app computes:
- Greedy schedule using a heuristic (e.g., by value or value/time)
- Optimal schedule using DP knapsack
- Total time and total value for each approach

Useful to see how greedy strategies differ from the true optimal solution.

---

### 1.3 Notes Search Engine

Search engine for lecture notes and documents using classic string-matching algorithms.

Supported file types:
- `.txt`
- `.pdf` (via `PyPDF2`)
- `.docx` (via `python-docx`)

Algorithms implemented:
- Naive search
- Rabin–Karp (rolling hash)
- KMP (Knuth–Morris–Pratt)

Features:
- Load a file and display basic info
- Type a pattern and choose:
  - Naive
  - Rabin–Karp
  - KMP
  - ALL (Compare) – runs all three
- Shows:
  - All match positions (starting indices)
  - Timing information for each algorithm, so you can compare performance

---

### 1.4 About / Info Tab

Provides a quick reference:

- Short description of each module (Campus Navigator, Study Planner, Notes Search)
- Big-O complexity summaries for:
  - BFS / DFS
  - Dijkstra
  - Prim
  - Naive / Rabin–Karp / KMP
- A brief explanation of what the app is and how it ties to algorithm practice

## 2. Tech Stack & Dependencies

- Language: Python 3.x  
- GUI:** Tkinter (standard library)  
- Core libraries: `heapq`, `collections`, `time`, `math`, etc.  
- For Notes Search file support:**
  - [`PyPDF2`](https://pypi.org/project/PyPDF2/) – PDF text extraction
  - [`python-docx`](https://pypi.org/project/python-docx/) – DOCX text extraction
